# Django-BBS 功能更新文档（改动前后对比）

> 本文档记录了本次新增的两个功能：**文章封面上传** 和 **评论@回复用户名**。
> 以下按文件逐一展示改动前后的对比。

---

## 一、功能概述

| 功能 | 说明 |
| --- | --- |
| 文章封面上传 | 后台发布/编辑文章时可选择上传封面图片；不上传时首页/站点列表用作者头像作为封面，上传了则用封面图。尺寸保持现有的 91×91px。 |
| 评论@回复用户名 | 子评论（回复）区域显示 "@被回复用户名"；点击"回复"按钮时评论框下方显示"正在回复 @用户名"提示，提交时携带 reply_user 参数。 |

```python
class Article(BaseModel):
    title = models.CharField(verbose_name='文章标题', max_length=128)
    content = models.TextField(verbose_name='文章内容(Markdown)')
    # 文章封面图片：用户在后台发布/编辑文章时可选择上传封面图片
    # 上传到 media/article_cover/ 目录下；default='' 表示默认无封面
    # 前端展示逻辑：有封面则用封面，无封面则回退用作者头像
    cover = models.ImageField(
        verbose_name='文章封面', upload_to='article_cover', default='', blank=True
    )
    up_num = models.IntegerField(verbose_name='点赞数', default=0)
    ...
```

**改动前：**

**改动后：**

```python
class Comment(BaseModel):
    ...
    parent = models.ForeignKey(
        to='self', verbose_name='父评论', on_delete=models.CASCADE,
        null=True, blank=True, related_name='children'
    )
    # 回复目标用户：子评论（回复）时，记录被回复的用户是谁
    # 用于前端展示 "@用户名" 功能；根评论时该字段为 None
    # related_name='reply_comments' 反向查询：user.reply_comments 获取该用户被回复的所有评论
    reply_to = models.ForeignKey(
        to='User', verbose_name='回复目标用户', on_delete=models.CASCADE,
        null=True, blank=True, related_name='reply_comments'
    )

    class Meta:
        ...
```

#### 改动点 ④：CommentView.post 新增 reply_to 保存逻辑

**改动前：**

```python
reply_user = request.POST.get("reply_user", "")
...
parent = None
if parent_id:
    parent = Comment.objects.filter(...).first()
    if not parent:
        return JsonResponse({'code': 400, 'msg': '父评论不存在'})

Comment.objects.create(
    user=request.user, article=article,
    content=content, parent=parent,

```

**改动后：**

```python
# 回复目标用户名：前端点击"回复"时传入被回复用户的 username
reply_user = request.POST.get("reply_user", "")
...
parent = None
if parent_id:
    parent = Comment.objects.filter(...).first()
    if not parent:
        return JsonResponse({'code': 400, 'msg': '父评论不存在'})

# 回复目标用户校验：通过 username 查找被回复的用户对象
# 如果是根评论（无 parent），reply_to 为 None；子回复时根据 reply_user 查找
reply_to_user = None
if reply_user:
    reply_to_user = User.objects.filter(username=reply_user).first()

# 创建评论，保存 reply_to 关系（@功能核心）
Comment.objects.create(
    user=request.user, article=article,
    content=content, parent=parent,
    reply_to=reply_to_user,
)
```

```javascript
// 封面文件选择后即时预览
$('input[name="cover"]').change(function () {
    var file = this.files[0];
    if (!file) { $('#coverPreview').hide(); return; }
    var reader = new FileReader();
    reader.onload = function (e) {
        $('#coverPreview').attr('src', e.target.result).show();
    };
    reader.readAsDataURL(file);
});
```

#### 改动点 ③：JS 回复按钮增加 replyUser 赋值和 @提示

**改动前：**

```javascript
$('.replyBtn').click(function () {
    $('#parentId').val($(this).data('id'));
    $('#cancelReply').show();
    $('#commentContent').focus();
});
$('#cancelReply').click(function () {
    $('#parentId').val('');
    $('#cancelReply').hide();
});
```

**改动后：**

```javascript
$('.replyBtn').click(function () {
    var replyUser = $(this).data('reply-user');      // 被回复用户名
    $('#parentId').val($(this).data('id'));           // 父评论（根评论）ID
    $('#replyUser').val(replyUser);                    // @功能：被回复用户名
    $('#cancelReply').show();                          // 显示"取消回复"按钮
    // @提示：显示"正在回复 @用户名"
    if (replyUser) {
        $('#replyHint').text('正在回复 @' + replyUser).show();
    } else {
        $('#replyHint').hide();
    }
    $('#commentContent').focus();
});
$('#cancelReply').click(function () {
    $('#parentId').val('');
    $('#replyUser').val('');  // 清空回复目标用户
    $('#replyHint').hide();   // 隐藏@提示
    $('#cancelReply').hide();
});
```
